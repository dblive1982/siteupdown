Traceroute from around the world

A traceroute shows the route your data takes to reach a server, one stop (hop) at a time, with the time each stop took. It helps show where a slow connection or a break happens.

This tool runs the trace from eight countries, using the public Globalping network, so you can compare routes from different parts of the world.

How to read the results

  • Each line is a hop, a router the data passed through on the way.
  • The time is how long that hop took to answer. It normally rises as the path gets longer.
  • A sudden big jump in time often marks a long-distance link, such as crossing an ocean.
  • Stars or blank hops are routers that do not reply to traceroute. That is common and does not mean a fault if later hops answer.

Questions

Why do some hops show no answer?

Many routers are set to ignore traceroute for security or to save effort. If the trace still reaches the end, the path is working.

Does a slow hop mean that router is broken?

Not necessarily. Routers often reply to traceroute slowly while still passing real traffic quickly. Look for a delay that stays high on every later hop.

Why does the path differ by country?

Each network picks its own route, and large sites use servers close to each region, so the destination itself can differ.
