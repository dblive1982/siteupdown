Ping test from around the world

A ping test sends a few tiny messages to a server and times how long each takes to come back. It is the simplest way to see how far away a server feels from different parts of the world.

This tool pings from fifteen places at once, using the public Globalping network. A site that answers quickly in one country and slowly in another is usually served from one region only, or is missing a content delivery network.

How to read the results

  • Average is the typical round-trip time in milliseconds. Under 50 ms feels instant, 50 to 150 ms is normal across a continent, and 200 ms or more is common between far-apart continents.
  • Min and max show the spread. A big gap between them points to an unstable connection.
  • Packet loss is the share of messages that never came back. Any steady loss is worth investigating.
  • No answer does not always mean a server is down. Many servers, and almost all large sites, ignore ping on purpose. Use the website checker to test the web page itself.

Questions

Why does a big website not answer ping?

Ping uses a different protocol from web pages. Many hosts block it for security, so a site can load perfectly while ping gets no reply.

Why are the times different in each country?

Distance matters. Signals travel at a fixed speed, so a server in London is always slower to reach from Sydney than from Paris, unless a CDN has a copy close to each visitor.

Is this the same as pinging from my own computer?

No. These probes are on other networks, so their results can differ from yours. That is the point: it shows what the rest of the world sees.
