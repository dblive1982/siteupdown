Port checker: is a port open?

A port is a numbered door on a server. Web pages use 80 and 443, secure shell uses 22, mail uses 25, 587 and 993, and a Minecraft server usually listens on 25565. If the door is open, something is listening behind it. If it is closed or blocked by a firewall, connections fail.

This tool tries to open a connection to the port you pick, from our server, and tells you what happened. It is handy for checking that a game server, website or mail server is reachable from outside your own network, or that a port you meant to keep private really is closed.

How to read the results

  • Open means our server connected, so something is listening and no firewall stopped us.
  • Closed means the server answered but nothing is listening on that port.
  • No answer usually means a firewall is silently dropping the connection, or the server is off. It can also mean our own hosting provider restricts that port, so treat it as a strong hint rather than proof.
  • Time is how long the connection took to set up, which is a rough sign of distance and load.

Questions

Why does it only offer certain ports?

We check a list of common service ports only. That keeps the tool useful for owners checking their own servers and stops it being used to scan networks.

My Minecraft server shows closed but works for me. Why?

If you can join from the same network but we cannot, the port is probably not forwarded on your router or allowed through your firewall. Forward TCP port 25565 to the computer running the server.

Does this test UDP ports?

No, only TCP. Many games use UDP for gameplay, so an open TCP port does not prove the game traffic will get through.

Is it safe to leave database ports open?

Usually not. Ports such as 3306 (MySQL), 5432 (PostgreSQL) and 3389 (Remote Desktop) should only be reachable from addresses you trust. If this tool says open and you did not expect it, restrict it in your firewall.
