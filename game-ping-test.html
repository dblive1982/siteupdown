Game ping test.

Press start and we time your connection to 17 cloud regions, closest first. It takes about 15 seconds and uses almost no data.

RegionPingRating

Which part of the world gives you the best ping? This test measures your connection to cloud regions that many online games and game services use.

This is a browser test against cloud regions, not against any one game's own servers, and it reads a little higher than in-game ping. We do not store your results. For your download and upload speed use the internet speed test, and to see whether a game is down use Is it down?

Getting a fair result

  • Use a cable if you can, or stand near the router.
  • Pause downloads and streaming first.
  • Turn off a VPN, which adds its own delay.
  • Run it twice and compare, because a single run can catch a busy moment.

Questions

What does this test?

It times how long your connection takes to reach cloud data centres in 17 regions around the world. Many online games and game services run their servers in the same regions, so it shows roughly what ping you could expect there.

Is this the same as the ping in my game?

Not exactly. It is a browser test, which usually reads about 15 to 20 ms higher than a game does, and it is not the game's own server. Use it to compare regions and spot a problem, not as an exact in-game number.

What is a good ping for gaming?

Under about 50 ms feels instant, up to about 100 ms is fine for most games, and over 150 ms is noticeable. Fast competitive shooters feel best under about 40 ms.

Why is my nearest region still slow?

Wi-Fi, a busy network, other devices downloading and a VPN all add delay. Try a cable, pause downloads and run the test again. Mobile data is also less steady than a home line.

What does steadiness mean?

It is how much the five measurements for a region varied. Steady connections feel smooth. Uneven ones cause rubber-banding even when the average looks fine.

Why does a region show no answer?

An ad blocker, a work or school network, or a VPN can stop the test reaching it. Turn those off for this page and try again.
