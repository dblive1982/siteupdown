500, 502, 503 and 504 errors: what server errors mean

Errors that start with a 5 are the website’s own problem, not yours. The request reached the server, and the server was unable to answer properly.

500 Internal Server Error

A catch-all. Something went wrong inside the site’s own code or configuration, and the server has no better description. Common causes are a bug after an update, a broken plugin, a script that ran out of memory, or a misconfigured file.

502 Bad Gateway

Large sites are often several servers working in a chain: a front server (a proxy or CDN) passes your request to a back server. A 502 means the back server sent the front one an invalid answer, or none at all. It often appears briefly while a site is being updated or restarted.

503 Service Unavailable

The server is up but cannot take your request right now. It is either overloaded or switched into maintenance mode on purpose. A 503 is meant to be temporary, and well-run sites send a Retry-After header that says when to try again.

504 Gateway Timeout

Like 502, but the front server gave up waiting. The back server was too slow, usually because it is overloaded or stuck on a heavy task such as a database query.

What visitors can do

  1. Wait a minute and reload. Many 5xx errors clear themselves.
  2. Check whether it is down for everyone: paste the address into the checker.
  3. If it is down for everyone, there is nothing to fix on your side. Come back later, or look for the site’s status page or social account.

What owners can do

  • Check the server error log first. It almost always names the file and line that failed.
  • If it started after an update, disable the last plugin, theme or change.
  • Look at memory and CPU use, and at how many requests are hitting the site.
  • Put a monitor on the site so you hear about it before your visitors do. A free watchlist emails you when a site fails twice in a row.
