HTTP status codes explained: what 200, 301, 404 and 503 mean

Every time a browser asks a website for a page, the server answers with a three-digit status code before it sends anything else. Most of the time you never see it. When something goes wrong, it is often the only clue about whose fault it is.

The five families

The first digit tells you the general story.

  • 1xx, informational. The server is working on it. You almost never see these.
  • 2xx, success. The request worked. 200 OK is the one you want.
  • 3xx, redirection. The page has moved and your browser should go somewhere else. 301 is a permanent move and 302 is a temporary one.
  • 4xx, a problem with the request. The server is up, but it will not give you that page. 404, 403 and 429 live here.
  • 5xx, a problem on the server. The server could not do what you asked. 500, 502, 503 and 504 live here.

The ones you will meet most

  • 200 OK: the page loaded normally.
  • 301 Moved Permanently: the address has changed for good. Search engines transfer the old address’s standing to the new one.
  • 302 Found / 307 Temporary Redirect: the page is somewhere else for now. Common for login steps and short-term campaigns.
  • 304 Not Modified: your browser already has the latest copy, so nothing was sent again. This is what makes repeat visits fast.
  • 400 Bad Request: the server could not understand the request, often because of a broken cookie or a malformed address.
  • 401 Unauthorized: you need to sign in first.
  • 403 Forbidden: the server understood you but will not let you in. See below.
  • 404 Not Found: there is nothing at that address. Read more in What does a 404 mean?
  • 429 Too Many Requests: you, or a network you share, have made too many requests too quickly. Wait a few minutes.
  • 500 Internal Server Error: something broke on the server. More on the 5xx errors.
  • 502, 503, 504: a gateway, overload or timeout problem between the servers that run the site.

Why 403 deserves a mention

A 403 usually means the site is working fine and has chosen not to serve you. Typical causes are a security rule that blocks your country or network, a firewall that flags automated traffic, or a page that needs an account. Our checker reports a blocked request as Inconclusive rather than Down, because the site is clearly answering.

What it means for site owners

Search engines read these codes too. A page that returns 200 but shows an error message (a “soft 404”) confuses them. A 5xx that lasts for days can make a page drop out of search results. Return the code that tells the truth.

The full reference

Here is every status code you are likely to meet, grouped by family, with what it means in plain English and what to do about it.

1xx: informational

  • 100 Continue: the server has seen the start of a large request and is happy for the rest to be sent. Browsers handle this silently.
  • 101 Switching Protocols: the connection is changing to a different protocol, most often a WebSocket for live features such as chat. Not an error.
  • 103 Early Hints: the server tells your browser which files it will need while it is still preparing the page, so loading starts sooner.

2xx: success

  • 200 OK: the request worked and the page came back.
  • 201 Created: something new was saved, such as a new account or post. Common in app and API traffic.
  • 202 Accepted: the server has taken the request and will deal with it later. It is not finished yet.
  • 204 No Content: it worked, and there is nothing to send back. Often used when saving a setting.
  • 206 Partial Content: only part of a file was sent, which is how video and large downloads load in pieces.

3xx: redirection

  • 301 Moved Permanently: the address changed for good. Search engines carry the old address’s standing across.
  • 302 Found: the page is elsewhere for now. Use it for short-term moves.
  • 303 See Other: after you submit a form, you are sent to a results or thank-you page so a refresh does not submit it twice.
  • 304 Not Modified: your browser already has the latest copy, so nothing was sent again.
  • 307 Temporary Redirect: like 302, but the browser must repeat the same kind of request at the new address.
  • 308 Permanent Redirect: like 301, but the browser must repeat the same kind of request at the new address. Used when a site moves from http to https and form data must survive.

If you see “too many redirects”, two addresses are sending you back and forth. Here is how to fix it.

4xx: the request has a problem

  • 400 Bad Request: the server could not make sense of the request. Clear the site’s cookies and check the address for odd characters.
  • 401 Unauthorized: you need to sign in, or your sign-in was not accepted.
  • 402 Payment Required: reserved for payment systems. A few services use it when an account or subscription has lapsed.
  • 403 Forbidden: the server understood you but will not serve you. More on 403.
  • 404 Not Found: nothing lives at that address. More on 404.
  • 405 Method Not Allowed: the page exists but does not accept that kind of request, for example submitting a form to a page that only displays content.
  • 406 Not Acceptable: the server cannot send the content in a format your browser said it could accept.
  • 408 Request Timeout: the server waited for your browser to finish sending the request and gave up. A slow or dropped connection is the usual cause.
  • 409 Conflict: the request clashes with the current state of things, such as two people editing the same item at once.
  • 410 Gone: the page was removed on purpose and will not return. Search engines drop a 410 page faster than a 404.
  • 413 Content Too Large: what you tried to upload is bigger than the server allows.
  • 414 URI Too Long: the web address is longer than the server will accept.
  • 415 Unsupported Media Type: the server does not accept that kind of file or data.
  • 418 I’m a teapot: a joke code from a 1998 April Fools’ specification. Some sites return it on purpose, and a few use it to turn away automated visitors.
  • 422 Unprocessable Content: the request was well formed but the contents were not valid, such as a form with a missing required field.
  • 429 Too Many Requests: too many requests in a short time. What to do.
  • 431 Request Header Fields Too Large: your browser sent too much cookie or header data. Clearing cookies for the site usually fixes it.
  • 451 Unavailable For Legal Reasons: the page is blocked because of a legal demand, for example in your country. The number is a nod to the novel Fahrenheit 451. More on blocked sites.

5xx: the server has a problem

  • 500 Internal Server Error: something broke on the server and it has no more specific answer.
  • 501 Not Implemented: the server does not support what you asked it to do.
  • 502 Bad Gateway: one server got a bad answer from another server behind it.
  • 503 Service Unavailable: the server is overloaded or down for maintenance. This usually passes.
  • 504 Gateway Timeout: one server waited too long for another behind it to answer.
  • 505 HTTP Version Not Supported: the server does not speak the version of HTTP your browser used.
  • 507 Insufficient Storage: the server has run out of space to complete the request.
  • 508 Loop Detected: the server found itself going round in circles while handling the request.
  • 511 Network Authentication Required: you must sign in to the network first, as on hotel, café or airport Wi-Fi.

More detail on the common server errors is in 500, 502, 503 and 504 explained.

Cloudflare’s own 52x codes

Many large sites sit behind Cloudflare, which adds its own error numbers. They are not official HTTP codes, but you will see them on error pages. They mean Cloudflare itself is working and the problem is between Cloudflare and the site’s own server (the “origin”).

  • 520 Web Server Returned an Unknown Error: the origin sent back something Cloudflare could not understand.
  • 521 Web Server Is Down: the origin refused the connection. The site’s server is off or blocking Cloudflare.
  • 522 Connection Timed Out: Cloudflare could not reach the origin in time.
  • 523 Origin Is Unreachable: Cloudflare could not find a route to the origin, often a DNS or network fault.
  • 524 A Timeout Occurred: the connection was made but the origin took too long to answer.
  • 525 SSL Handshake Failed: Cloudflare and the origin could not agree on a secure connection.
  • 526 Invalid SSL Certificate: the origin’s certificate is not valid. More on certificate errors.
  • 530: usually shown alongside a Cloudflare 1xxx error such as 1016, meaning Cloudflare cannot resolve the site’s origin. For visitors this means the site’s owner has a configuration problem to fix.

As a visitor you can do nothing about a 5xx or 52x code except wait and try again. As a site owner, check your origin server, firewall and certificate first.
